# Falar — офлайн-переводчик pt-BR ↔ ru в наушнике

Приложение для Android: слушать бразильскую речь и получать русский перевод в ухо, говорить
по-русски и получать бразильский португальский вслух или крупным текстом на экране, а заодно
учить слова из собственных разговоров. Всё считается на телефоне: распознавание (parakeet),
перевод (OPUS-MT), синтез (Piper), словарь на 190 тысяч фраз. Сеть нужна только для необязательного
пересмотра разговора бесплатной облачной моделью, и только по кнопке или явно включённому интервалу.

«Falar» — «говорить»: то, о чём приложение просит собеседника («Pode falar»), и то, чему учит вас.
До версии 0.21 проект назывался AgentTranslator.

Требования: телефон на arm64 с Android 9 и новее; для полной сборки с локальным уточнителем —
от 6 ГБ памяти. Модели занимают около 1,9 ГиБ обязательных и 1,1 ГиБ необязательных.

Сборка без Gradle: `bench/apk/build.sh` (javac + D8 + aapt2 + zipalign + apksigner), модели —
`python3 tools/models_fetch.py`, заливка на телефон — `bench/apk/push_models.sh`.
