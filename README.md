## Что он делает

- **Переводит вживую.** От конца фразы до перевода в ухе около секунды на телефоне пятилетней давности.
- **Показывает крупно.** Когда вы в наушниках, вывести португальский в динамик нельзя ни одним
  штатным способом, поэтому собеседник читает свою сторону с экрана. Под словами — как их прочесть
  вслух, русскими буквами с ударением.
- **Работает в самолёте.** Сеть нужна один раз, чтобы скачать модели.
- **Учит словам.** Слова из ваших разговоров собираются в отдельную вкладку.
- **Правится на ходу.** Свою реплику можно исправить прямо в разговоре, и приложение запомнит
  исправление. Плохой перевод можно отправить в обсуждения проекта прямо из меню реплики.

Внутри: parakeet для распознавания, OPUS-MT для перевода, Piper для голоса, словарь на 190 тысяч
фраз. Всё считается на телефоне. Необязательный пересмотр разговора бесплатной облачной моделью
выключен, пока вы не включите его сами.

«Falar» по-португальски значит «говорить»: то, о чём приложение просит собеседника («Pode falar»),
и то, чему учит вас. До версии 0.21 проект назывался AgentTranslator.

Требования: телефон на arm64 с Android 9 и новее; для полной сборки с локальным уточнителем —
от 6 ГБ памяти. Модели занимают около 1,9 ГиБ обязательных и 1,1 ГиБ необязательных.

Сборка без Gradle: `bench/apk/build.sh` (javac + D8 + aapt2 + zipalign + apksigner). Модели
приложение качает само при первом запуске по манифесту, вшитому в APK (`models/manifest.json`):
обязательное с экрана первого запуска, необязательное — из «Системы». Для стенда зеркало собирает
`python3 tools/models_fetch.py`, на телефон его заливает `bench/apk/push_models.sh`.
Тесты загрузчика: `bash bench/apk/test.sh` (стол), `bash bench/apk/test_models_device.sh` (телефон).

Публичная сборка подписывается ключом, которого нет в репозитории:

```bash
FALAR_KEYSTORE=~/falar-release.keystore FALAR_KS_PASS=… bash bench/apk/build.sh
```

Без этих переменных сборка подписывается отладочным ключом и годится только для стенда.
